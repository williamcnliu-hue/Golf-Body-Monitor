# 🏌️ Golf Body Monitor · 高尔夫身体监控

> 一套帮自己**监控身体状态、固化训练 SOP、辅助下场决策**的个人系统。

🔗 **在线使用**：https://williamcnliu-hue.github.io/Golf-Body-Monitor/

---

## 这个工具解决什么问题

Strava 记录运动数据，WHOOP 记录身体数据，但**没有人记录"身体状态如何翻译成下场决策"**。

把身体状态变成数字，让数据替你做判断——这是这个工具想补上的空白。

---

## 核心逻辑

\`\`\`
数据沉淀 → 找规律 → 做判断 → 指导行动
\`\`\`

例：今天整体身体 70 分，重要肌肉就别发超过 70 分的力——
把身体状态翻译成下场决策。

---

## 现在能做什么（V6 已上线）

- **34 块肌肉热区**：在真实人体解剖图上，点击任意一块肌肉打分（0–100）
- **健康度可视化**：圆点按历史平均分自动变色 🟢 绿(75+) / 🟡 黄(50–74) / 🔴 红(<50)
- **今日整体分**：环形仪表实时显示当天平均状态
- **决策提示**：根据整体分给出"今天别发超过 X 分的力"的下场建议
- **按天归档**：每天数据独立保存，可查看趋势变化（↑ ↓ →）
- **一键导出**：导出过往数据存档，永不丢失
- 数据存浏览器本地，**手机、电脑随时打卡**

## 未来计划（三层结构）

这个工具完整形态分三层，目前只做了第一层的雏形。

### 第一层 · 身体状态监控（✅ 已上线 + 持续增强）
把人体当机器，实时掌握状态：哪块肌肉给力、哪块不给力、哪块有旧伤。

| 计划功能 | 说明 |
|---------|------|
| 整体趋势图 | 哪块肌肉长期偏弱、哪块容易劳损，一眼看出 |
| 代偿监控 | 某块肌肉伤了/没力，身体让别块替它出力，监控替了多少 |
| 弹性而非力量 | 监控肌肉的弹性 + 瞬间爆发，不只是力量大小 |
| 年龄线提醒 | 上年纪的肌肉需要更密的监控 |
| AI 康复建议 | 把劳损肌肉数据交给 AI，生成针对性恢复方案 |
| AI 训练建议 | 针对发力薄弱的肌肉，生成定制训练计划 |
| 自动存档 | 每天数据定时归档，免手动导出 |

### 第二层 · 训练 SOP 固化（规划中）
把正确动作拆成可复用的 SOP（瞄准 → 启动 → 哪块肌肉放松 → 击球 → 收杆 → 上杆），
反复练 → 形成肌肉记忆 → 下场自动调用。核心理念：动作固化的本质是给神经排序。

### 第三层 · 下场决策系统（规划中）
打球是多变量、限时的决策问题（场地、风、果岭速度、距离……）。
目标：在最短时间内决定用哪只杆 + 做哪套动作。

| 计划功能 | 说明 |
|---------|------|
| 战术卡库 | 不同场景对应不同动作组合，像调取战术卡一样快速决策 |
| 状态机管理 | 好球进"乘胜追击"，坏球进"清零重置"，管理心理状态 |
| 选杆测算 | 把场地变量算进去，辅助选杆 |
